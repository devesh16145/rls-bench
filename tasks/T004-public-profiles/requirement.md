A community site. Each user can have one public profile; a profile's `id` is the id of the user it belongs to.

R1. Anyone, including anonymous visitors, can read every profile.
R2. Signed-in users can create a profile only for themselves.
R3. Users can edit only their own profile, and cannot move it to another user's account.
R4. Profiles cannot be deleted through the app, not even by their owner.
R5. Anonymous visitors cannot create or change profiles.
R6. Server-side code using the service role keeps full access.
